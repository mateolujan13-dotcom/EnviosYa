Cómo leer estos wireframes: cada frame representa una pantalla con su ruta y prioridad. El objetivo es validar jerarquía, densidad, ubicación de acciones y estados antes de generar los mockups de alta fidelidad. Los datos son de ejemplo y coinciden con el PRD (EY-4F8A1C, Córdoba → Rosario, ARS 81.700). El diseño visual final se define con Google Stitch a partir de DESIGN.md y stitch-prompt.md.
